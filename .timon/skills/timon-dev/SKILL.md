# Working on timon with timon

This repository has its own project layer. Trust it once per checkout after reading it:

```sh
timon trust        # from the repository root
timon defs         # the layers, settings, agents, scripts and lib in effect
```

## Tasks

```sh
timon tasks                   # the gates (tasks.lua) and the scripts, with descriptions
timon check                   # every gate before a push; exits with the first failure's code
timon quick                   # format and lint only
timon test -- --test tasks    # one gate; words after -- go to cargo test
timon em-dash                 # fails on any em dash in our own text; also runs in cargo test
timon recent 6h               # recent timon sessions and recorded agent runs
timon naming-audit            # the namer agent over six areas; spends tokens (limit $2)
timon bump --version 0.2.0    # a pull request that sets the version
timon release                 # after it merges: check, tag, push, GitHub release (asks first)
timon update                  # install main and update the plugin in Claude Code and Codex
timon fix-issues 117,118 119  # the fixer agent per group of issues, in worktrees; spends tokens
```

`bump` and `release` live in `.timon/lib/release.lua`; `tests/release.rs` runs them against a
sandbox crate, a bare remote and a local GitHub API.

## Agents

```lua fragment
local r = agent.run{ agent = "reviewer", prompt = "Review src/options.rs and its tests" }
if r.status == "ok" then pp(r.answer.findings) end
```

`reviewer` reads AGENTS.md and the design and returns the `review` contract. `namer` extends it
for the naming review (#52) and returns `naming`. `init.lua` caps the project at $2 per
invocation.

## Where things live

| Path | What |
|---|---|
| `src/modules/` | the Lua modules and their `DOC` declarations |
| `src/agent/`, `src/sessions/` | providers, run records, session archives and the index |
| `skills/` | built-in skills; every `lua` block runs in `tests/skills.rs` |
| `plugin/` | `skills/` is generated by `timon plugin build plugin`, never edited by hand; the manifests, `hooks/hooks.json` and `bin/timon` are checked-in files |
| `.timon/` | this project layer |
