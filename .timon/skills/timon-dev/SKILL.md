# Working on timon with timon

This repository has its own project layer. Trust it once per checkout after reading it:

```sh
timon trust        # from the repository root
timon defs         # the layers, settings, agents, scripts and lib in effect
```

## Scripts

```sh
timon run em-dash             # fails on any em dash in our own text; also runs in cargo test
timon run recent 6h           # recent timon sessions and recorded agent runs
timon run naming-audit        # the namer agent over six areas; spends tokens (limit $2)
```

## Agents

```lua fragment
local r = agent.run{ agent = "reviewer", prompt = "Review src/options.rs and its tests" }
if r.status == "ok" then pp(r.answer.findings) end
```

`reviewer` reads AGENTS.md and the design and returns the `review` contract. `namer` extends it
for the naming review (#52) and returns `naming`. `init.lua` caps the project at $2 per
invocation.

## Where things live

| Path | What |
|---|---|
| `src/modules/` | the Lua modules and their `DOC` declarations |
| `src/agent/`, `src/sessions/` | providers, run records, session archives and the index |
| `skills/` | built-in skills; every `lua` block runs in `tests/skills.rs` |
| `plugin/` | generated by `timon plugin build plugin`; never edit by hand |
| `.timon/` | this project layer |
